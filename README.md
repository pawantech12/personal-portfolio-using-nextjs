# Mumair - Responsive Personal UI/UX Designer Portfolio 💼

**Mumair** is a responsive and modern portfolio template for UI/UX designers, developed using **Next.js** and **TailwindCSS**. This sleek and stylish portfolio highlights your professional skills, services, and projects in a visually appealing manner, offering an engaging user experience.

[Mumair Portfolio Preview](https://www.youtube.com/watch?v=6AWekPR2q3k) 

## ✨ Features

- **Hero Section:** Captures attention with a captivating introduction.
- **About Section:** Showcase your story, skills, and experience.
- **Services Section:** Highlight your offerings with hover effects for interactivity.
- **Portfolio Section:** A working portfolio with tabs and smooth transitions for seamless navigation between categories.
- **Contact Section:** A functional and accessible way to connect.
- **Header and Footer:** Includes a responsive navigation bar and a polished footer.
- **Responsive Design:** Optimized for mobile, tablet, and desktop views.

## 🛠️ Tech Stack

- **Next.js:** Framework for building high-performance React applications.
- **TailwindCSS:** Utility-first CSS framework for responsive and customizable design.


## 📋 Installation

Follow these steps to set up the project locally:

1. **Clone the Repository:**

   ```bash
   git clone https://github.com/pawantech12/personal-portfolio-using-nextjs.git
   ```

2. **Navigate to the Project Directory:**

   ```bash
   cd personal-portfolio-using-nextjs
   ```

3. **Install Dependencies:**

   ```bash
   npm install
   ```

4. **Start the Development Server:**

   ```bash
   npm run dev
   ```

5. **View in Browser:**

   Open [http://localhost:3000](http://localhost:3000) to see the portfolio in action.


## 🛠️ Customization

You can easily modify the sections, colors, or layout using the component structure and TailwindCSS utility classes. For example:

- Update the **hero content** in `components/Hero.js`.
- Modify **portfolio items** in `components/Portfolio.js`.
- Edit **services** in `components/Services.js`.
